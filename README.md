# 儿童自然拼读课程编排工具

面向自然拼读教师的纯前端课程设计工具。老师可以组织音素、单词、句子和练习，检查教学顺序与质量，并在本机离线继续编辑。

## 功能

- 按音素、单词、句子、练习四类活动编排课程。
- 设置活动难度、预计时长、教学提示、无障碍说明和练习反馈。
- 使用复选框建立前置活动依赖，并检测循环依赖和失效引用。
- 手机、平板、桌面三种预览宽度，按课程顺序查看学习路径。
- 自动检查音素提前使用、相似音混淆、例句过长、练习缺少反馈、无障碍说明缺失。
- 活动上移、下移、复制、删除，以及整门课程复制。
- 保存完整课程快照并比较两个版本的活动增删和字段变化。
- 多标签页本地协作：每个标签页带课程修订号，保存时三向合并互不重叠的字段；活动顺序、依赖或音素被双方同时修改时保留双方草稿与冲突说明，逐项确认后才生效。
- 活动一变，旧检查结果和未封存版本立即标记过期并自动重算；过期版本不能再用于比较或复制，封存后的版本长期有效。
- 冲突处理中断（关闭面板、刷新、标签页崩溃）后，双方草稿和冲突记录仍保存在本机，可随时找回并重试。
- 所有数据自动保存到 localStorage，断网后仍可编辑。
- `Ctrl/Cmd+Z` 撤销、`Ctrl/Cmd+Y` 重做、`Alt+N` 新建活动、`Alt+↑/↓` 调整顺序、`Ctrl/Cmd+S` 保存（冲突面板打开时等同“确认并生效”）。

## 技术栈

- SvelteKit + TypeScript
- Svelte 5
- Carbon Components Svelte
- Vite
- 浏览器 localStorage
- Nginx 静态部署

## 本地开发

```bash
npm install
npm run dev
```

开发服务器监听 `5173`，宿主端口仅由部署映射，源码未写入 `10026`。

## 生产构建

```bash
npm install
npm run build
```

静态产物位于 `build`。也可以执行 `npm run check` 做 Svelte/TypeScript 检查。

## 本地协作保护

- 课程带有单调递增的修订号 `revision`，每次成功保存 +1；顶栏显示当前修订号与标签页编号。
- 每个标签页会把“共同基线 + 当前草稿”周期性写入 localStorage。保存时若发现其他标签页的修订更新，以共同基线做三向合并：
  - 只有一方改动的字段直接采用；双方改不同字段自动合并；双方改成相同值也不冲突；
  - 音素、依赖支持“采用本页 / 采用对方 / 合并双方集合（音素还可手动指定）”；
  - 顺序双方都调整时先尝试双方顺序的并集拓扑，先后关系矛盾时才要求老师选择；
  - 删除与编辑同一活动、整门课程被复制成不同主体时也会要求确认。
- 冲突面板会展示双方草稿原文，必须逐项确认后“确认并生效”才会写入；确认期间对方又保存了修订会自动刷新冲突清单。关闭面板或处理失败后，冲突记录（含三方草稿）仍在 localStorage，横幅可随时找回；其他标签页崩溃遗留的草稿也能通过“找回并重新合并”恢复。
- 活动指纹变化后，上一份检查报告立即标记过期并按当前修订重算；未封存版本同样立即过期，从比较下拉列表中移除且不能复制，点击“封存此版本”后快照长期有效。
- `npm run test:merge` 运行三向合并、过期与失效依赖清理的逻辑测试。

## Docker

```bash
docker build -t sologsb-1026 .
docker run --rm -p 10026:80 sologsb-1026
```

容器内 Nginx 监听 `80`，访问 `http://localhost:10026`。课程数据仅保存在当前浏览器。
